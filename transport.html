📝 注意事項

1. 指定席預約：全九州 JR Pass 可免費預約指定席。由布院之森為全車指定席，必須預約。豪斯登堡號有自由席但黃金週建議劃位。可透過 JR 九州線上預約或車站みどりの窓口辦理。
2. 黃金週注意：5/1-5/5 為日本黃金週，列車和景點都會非常擁擠。建議所有 JR 特急都提前預約指定席。
3. IC 卡：福岡地下鉄和西鉄電車可使用 SUGOCA / ICOCA / Suica 等 IC 卡，方便快速。
4. JR Pass 使用範圍：JR Pass 不適用於西鉄電車、福岡市地下鉄、巴士。僅適用於 JR 九州營運的列車。
